# vite-ality

Using Vitest framework written in vite - `https://vitest.dev/`

## SCOPE

Vitest is a unit test framework not too different from Jest.

## DIRECTIONS

1. Install vitest - `npm install -D vitest` 
2. Write tests - naming convention is something like `function.test.js` or `function.spec.js`
   1. If using TYPESCRIPT, name the test `.test.ts`
3. Run tests - `npm run test` (this is different of you use a different package manager)
   1. To run a specific test by name or directiory - `npm run test ./tests/**.test.js`
4. CLI Documentation - `https://vitest.dev/guide/cli`
